## Run Locally

**Prerequisites:** Node.js and npm.

```bash
git clone https://github.com/Psudhanshu-07/Porfolio.git
cd Porfolio
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

### Other Commands

```bash
npm run typecheck
npm run build
npm run start
```

Run `npm run build` before `npm run start` to serve the production build.
